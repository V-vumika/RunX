# Support

**Something broken?** Open a GitHub issue using the bug report template —
include the language, the code you ran, and what you expected vs. what
happened.

**Have an idea?** Open a GitHub issue using the feature request template.

**Something insecure?** See `SECURITY.md` instead of a public issue.

There's no chat/forum for RunX yet — GitHub issues are the single channel
for bugs, questions, and feature requests.
